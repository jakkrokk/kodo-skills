# title
Shipping KODO skill samples for faster onboarding

# desc
Added practical output samples so users can quickly understand expected KODO markdown style and structure.

# body
Today we focused on reducing onboarding ambiguity for new users of `kodo-skills`.

We added concrete output samples for both `PROJECT.md` and `YYYYMMDD.md` so users can copy, adapt, and publish quickly. The main reason for this change was that templates alone explain structure, but examples explain writing quality and tone.

As a result, users can now see both the required heading format and the narrative style we expect for daily updates.

Next, we plan to add scenario-based samples (release day, bug-fix day, and architecture change day) to make adoption even smoother.
