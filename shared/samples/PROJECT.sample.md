# title
KODO Skills Public Rollout

# desc
A reusable skill set for generating KODO markdown files across Codex, Claude Code, and OpenClaw.

# body
This project standardizes how daily build logs and project summaries are written in KODO format.

The goal is to reduce formatting friction and improve consistency, so users can focus on sharing progress narratives instead of managing markdown structure manually.

Current scope:
- `kodo-log-writer` skill variants for Codex / Claude Code / OpenClaw
- Shared templates and references
- Narrative-first daily log style with safety redaction rules

Next scope:
- More sample outputs by scenario (feature launch, refactor, incident response)
- Optional quality checks for heading completeness and tone consistency
